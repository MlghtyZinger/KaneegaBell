# KaneegaBell (KB): project instructions

Read these in order. Where they disagree, the later file wins.

1. @CLAUDE.updated.md is the project as built: milestones 0 and a-h, every decision that
   changed the original plan, performance numbers and working rules.
2. @CLAUDE.new1.md is the Phase 2 brief: the KaneegaBell rename, installer and auto-updater,
   resolutions, sidebar, icons, collections, themes, animations, new platforms, and milestones
   i-r. It overrides the file above.

`CLAUDE.original.md` is the first brief. It's kept for history and isn't an instruction; it's
superseded by the two files above (for example, controllers use SDL3, not gilrs, and
MobyGames was dropped).
