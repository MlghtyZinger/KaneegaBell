## Part 1: "Search logos…" for a collection (SteamGridDB, user's own key)

### Backend
- `src-tauri/src/collections.rs`
  - Split `set_logo_file` into `set_logo_bytes(conn, data_dir, key, &[u8])` (the
    `store_logo_at` + `collection_looks` upsert) and a thin `set_logo_file` that reads the
    file and calls it. Same error text as today.
- `src-tauri/src/art/extras.rs` (next to `candidates`)
  - `pub fn search_logos(sgdb: &Sgdb, query: &str) -> Result<Vec<Candidate>>`:
    `sgdb.search(query)`, take the first **5** games, `sgdb.images(Kind::Logo, game.id)` for
    each (the client already spaces requests 250 ms apart and backs off on 429), map to
    `Candidate { source: "sgdb", name: img.id, preview: Some(thumb), url, label }` with
    label `"<SGDB game name> · W×H"`. Empty query → empty list. Skip a game whose logo
    call fails (log a warning) unless every call failed (then return that error).
  - Filtering stays SteamGridDB's own (the client already asks for static, SFW, non-humor,
    non-epilepsy images; check the logo path keeps those flags).
- `src-tauri/src/commands.rs` (beside `set_collection_logo_file`)
  - `collection_logo_candidates(app, key, query: Option<String>)`: `spawn_blocking`, like
    `cover_candidates`. Query defaults to the collection's name. No key →
    `Error::msg("A SteamGridDB key is needed to search for logos. Add one in Settings → Game info.")`.
  - `set_collection_logo_url(app, key, url)`: `spawn_blocking`; only accept `https://`
    URLs whose host is `steamgriddb.com` or ends with `.steamgriddb.com` (the image CDN,
    e.g. `cdn2.steamgriddb.com`; parse the host, don't substring-match: trust boundary,
    the page passes the URL back);
    download with `art::http::Http`, then `collections::set_logo_bytes`.
  - Register both in `lib.rs`'s `invoke_handler`.
- Tests (fake HTTP, `art::http::fake`): `search_logos` takes at most 5 games and keeps
  SGDB's order; one failing game is skipped; all failing returns the error;
  `set_collection_logo_url` rejects a non-SteamGridDB URL; `set_logo_bytes` bumps
  `logo_version` (extend `collections/tests.rs`).

### Frontend
- `src/api/index.ts`: `collectionLogoCandidates(key, query?)`,
  `setCollectionLogoUrl(key, url)`.
- `src/dev/mockIpc.ts`: mock both (a few fake candidates with preview URLs; set logo
  like `set_collection_logo_file`) so the preview works.
- `src/components/Collections.tsx`, collection editor, Logo row: a **"Search logos…"**
  button after "A game's logo…". It opens a panel with a search box (prefilled with the
  collection's name, on-screen keyboard via `editWithOsk`, Enter/A searches) and a grid of
  results in `col-choices`/`col-choice logo` style (preview images, `loading="lazy"`).
  "Searching SteamGridDB…" while it runs; the error text in `error()` if it fails (the
  no-key message tells the user where to add one). Picking one calls
  `setCollectionLogoUrl`, reloads collections, closes the panel; the logo then shows as
  "Your image" (it is saved as the collection's own file). Controller: D-pad moves, A picks,
  B closes the panel.
- Update the hint under the Logo row: mention SteamGridDB search needs the user's key.

## Part 2: TV Mode Collections tab

- `src/state/library.ts`: `tvTabs` keeps `"collections"` (stop filtering it out).
- `src/views/TvMode.tsx`
  - Remove the "start from All" line.
  - `const overview = () => library.platform() === "collections"`. In the overview the
    shelf lists `collections.visible()` instead of `games()`, same windowing; every tile
    uses one fixed aspect (square, `CollectionTile`'s look) so `offsets` stays simple.
    Keep a separate focus index for the overview (`colFocused` signal) so coming back
    from a collection lands on the one you opened.
  - Background: the focused collection's first member with a hero (else blurred cover),
    same settle + crossfade code (feed it that game).
  - Info area: the collection's logo (`chosenPicture` / `autoLogo`) or name, kind label
    (Collection / Smart collection / Series / Franchise) and the game count.
  - A on a tile → `library.setPlatform("col:" + key)` (the shelf becomes its games;
    everything else works as today). B in a collection → back to `"collections"` with the
    tile focused. B in the overview does what B does on other tabs today.
  - Y (favorite) and the letter jump do nothing in the overview; search still works
    across games.
  - Empty overview: "No collections yet. Make one on the desktop."
- No editing in TV Mode (stays on desktop).
